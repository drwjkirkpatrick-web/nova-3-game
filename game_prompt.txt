Create "NOVA-3" — a browser-based space trading and combat game inspired by Escape Velocity Nova (2002).

CONCEPT:
Top-down 2D space game. Player pilots a ship between star systems, trades commodities, fights pirates and aliens, upgrades ships, takes missions, and explores a living galaxy. Newtonian momentum physics. Real-time combat.

CORE GAME:

1. SHIP PHYSICS: Newtonian momentum — thrust applies acceleration, ship coasts when not thrusting. Rotation with left/right arrows. Up = thrust (engine flame visible). Down = reverse thrust. Top speed cap with momentum drift.

2. STAR MAP: Galaxy map with 6-8 star systems connected by hyperspace lanes. Press M to open map. Click a connected system to hyperspace jump (consumes fuel). Each system has a planet/spaceport.

3. PLANET LANDING: Fly near a planet and press L to land. Shows spaceport interface:
   - Trade commodities (buy low, sell high — prices vary by system)
   - Shipyard (buy new ships with different stats: speed, shields, weapons, cargo)
   - Outfitter (buy upgrades: better weapons, shield boosters, afterburners, cargo expansions)
   - Mission computer (accept cargo runs, bounty hunts, passenger missions)

4. COMBAT: Real-time top-down space combat. SPACE fires lasers/missiles. Enemy ships (pirates, aliens) with AI: chase, shoot, flee when damaged. Ships have shields (regenerate) and armor (hull damage = permanent until repaired at spaceport). Explosions with particle debris.

5. TRADING: 6 commodity types (food, metals, medicine, tech, luxury, contraband). Each system produces some cheaply and demands others at premium. Buy low, sell high. Cargo limited by ship capacity. Dynamic prices shift slightly each visit.

6. SHIPS: 4-5 ship classes:
   - Shuttle (starter: slow, small cargo, weak shields)
   - Cargo Freighter (big cargo, slow, decent shields)
   - Fighter (fast, strong shields, small cargo, good weapons)
   - Warship (best shields/weapons, medium cargo, expensive)
   - Each with unique sprite shape drawn on canvas

7. MISSIONS: 3 mission types:
   - Cargo delivery: take X units of commodity to system Y by deadline
   - Bounty: hunt a specific pirate in a named system
   - Passenger: transport VIP to a system (requires passenger quarters)

8. ECONOMY: Start with 5000 credits. Earn through trade, missions, bounty hunting. Ship upgrades cost credits. Death = lose uninsured cargo (insurance purchasable).

9. PERSISTENCE: Save game state to localStorage — credits, ship, cargo, system, missions. Auto-save on planet landing.
